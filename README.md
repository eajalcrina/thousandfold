# ThousandFold

Iniciativa colectiva de branding regenerativo para América Latina.

## Stack

- Next.js 15 (App Router)
- React 19 + TypeScript
- Tailwind CSS v4
- motion/react (Framer Motion v12)
- Supabase

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)
